# SENTINEL AI 🚗

### AI-Powered Driver Monitoring & Collision Avoidance System

SENTINEL AI is a driver-safety monitoring system designed to demonstrate how computer vision, machine learning, real-time alerts, and edge-computing concepts can be combined for intelligent vehicle safety.

The project provides a real-time monitoring dashboard for driver attention, road hazards, alerts, incidents, and system performance.

---

## 🚀 Features

- Driver monitoring dashboard
- Driver alertness monitoring
- Drowsiness detection simulation
- Driver distraction detection simulation
- Pedestrian and vehicle detection simulation
- Collision-risk alert simulation
- Real-time alert feed
- Trip monitoring
- Incident tracking
- System performance monitoring
- Analytics dashboard
- System activity logs
- Responsive interface

---

## 🧠 AI Monitoring States

The application demonstrates four monitoring states:

| State | Description |
|---|---|
| SAFE | Driver and road conditions are normal |
| DISTRACTED | Driver distraction detected |
| DROWSY | Possible driver drowsiness detected |
| OBSTACLE DETECTED | Potential road obstacle detected |

The simulation cycles through these states to demonstrate how an intelligent driver-monitoring system can respond to changing safety conditions.

## ⚡ Edge AI Considerations

The original project concept was designed with embedded vehicle deployment in mind.

Potential target hardware includes:

- Raspberry Pi
- NVIDIA Jetson Nano

Important deployment considerations include:

- Inference latency
- Power consumption
- CPU/GPU utilization
- Lightweight machine-learning models
- Edge inference vs cloud inference

---

## 🎯 Project Objective

The objective of SENTINEL AI is to demonstrate a practical AI-based vehicle safety monitoring concept that can identify driver-risk conditions and potential road hazards while providing real-time feedback through a monitoring dashboard.

---

## ⚠️ Project Note

This GitHub version contains an interactive simulation of the monitoring and alert pipeline.

The displayed camera detections and system-performance values are simulated/demo values and should not be interpreted as measurements from an actual vehicle, embedded device, or production safety system.
